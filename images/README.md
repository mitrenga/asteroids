# images/ — the app icons, the poster and the cover

| file | what it is |
|---|---|
| `poster.png` | poster 1448 × 1086 (operator, 2026-11-07): the Open Graph image of `index.php` |
| `cover.png` | cover 800 × 600 for `/about` (`aboutPage.php`), the poster scaled down: `convert images/poster.png -resize 800x600 images/cover.png` |

saucer over a starfield), not the original's graphics.
